Memory Hierarchy Speed Comparison

This visualization shows dots moving back and forth on parallel lanes representing different memory types. The speed of each dot is inversely proportional to the typical latency of that memory type. Faster memories (lower latency) have faster-moving dots.

Approximate latencies used (in nanoseconds):
- L1 Cache: 1 ns
- L2 Cache: 4 ns
- L3 Cache: 15 ns
- DRAM: 60 ns
- SSD: 150,000 ns
- HDD: 5,000,000 ns
